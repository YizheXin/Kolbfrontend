This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

1. Firstly, npm install dependencies in your local enviroment.

```bash
npm install
```
2. Add `.env` file in your root directory, if you don't have please contact the admin to get.
3. Start the application in your local machine.
```bash
Then start the server locally
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
4. Open the browser with your google email (which has the permission to access ics-analysis-dev GCP project)
and open [http://localhost:3000](http://localhost:3000) with your browser to see the Interface.
## Note:
If you login with an account doesn't have the permission to acccess ics-analysis-dev project, you would not see the the images display.
